# Data Sufficiency - Mental Math Solutions

[⬅️ Back to Main Navigation](../README.md) | [📖 Read Cheatsheet](./04_Logical_Reasoning_CheatSheet.md)

This document contains step-by-step mental math strategies for ALL 15 questions.

**Answer Key:** a) St1 alone sufficient  b) St2 alone sufficient  c) Both together  d) Either alone  e) Neither sufficient

---

### Question 1
**Question:** What is x? St1: 3 < x < 5. St2: x² = 16.
*   **Mental Trick:** St1: x between 3-5 (not unique). St2: x = ±4. Together: x = 4 (only value in range).
*   **Answer:** **c) Both statements together**.

### Question 2
**Question:** Is x > 0? St1: -2x < 0. St2: x³ > 0.
*   **Mental Trick:** St1: -2x < 0 → x > 0 ✅. St2: x³ > 0 → x > 0 ✅. Either works.
*   **Answer:** **d) Either statement alone**.

### Question 3
**Question:** How many black ewes in 50 sheep? St1: 10 rams. St2: 40% black.
*   **Mental Trick:** St1: 40 ewes, but how many black? Unknown. St2: 20 black, but gender split? Unknown. Together: 20 black total, 10 rams. But we don't know how many black are rams vs ewes. Insufficient.
*   **Answer:** **e) Neither sufficient**.

### Question 4
**Question:** Is side of equilateral E < side of square F? St1: Perimeters equal. St2: height:diagonal = 2√3:3√2.
*   **Mental Trick:** St1: 3s_E = 4s_F → s_E = 4s_F/3 > s_F. So E's side is longer. Answers the question: No. Sufficient.
*   St2: Height of E = s_E×√3/2. Diagonal of F = s_F√2. Ratio = (s_E√3/2)/(s_F√2) = 2√3/3√2 → s_E/s_F = (2√3×2√2)/(3√2×√3) = 4√6/(3√6) = 4/3. Same result. Sufficient.
*   **Answer:** **d) Either statement alone**.

### Question 5
**Question:** What % of b is a? St1: a = 3/11. St2: b/a = 20.
*   **Mental Trick:** Need a/b × 100. St1 alone: no b info. St2 alone: b/a = 20 → a/b = 1/20 = 5%. Sufficient.
*   **Answer:** **b) Statement 2 alone**.

### Question 6
**Question:** Is z even? St1: 5z is even. St2: 3z is even.
*   **Mental Trick:** St1: 5z even. If z is even, 5z even ✅. If z is odd, 5z is odd. So z must be even. Sufficient.
*   St2: same logic with 3z. Sufficient. Either works.
*   **Answer:** **d) Either statement alone**.

### Question 7
**Question:** When did Santosh reach college? St1: 10km away. St2: Speed 40kmph.
*   **Mental Trick:** We know distance (10) and speed (40), but not departure time. Can't find arrival time. Both together still lack start time.
*   **Answer:** **e) Neither sufficient**.

### Question 8
**Question:** 2 socks from drawer (black+white). P(both white)? St1: P(first black) = 1/3. St2: 24 white socks.
*   **Mental Trick:** St1: 1/3 are black → 2/3 white. But total unknown → can't compute exact probability. St2: 24 white but total unknown. Together: 1/3 black → white = 2/3. If total = n, white = 2n/3 = 24 → n = 36. P = (24/36)(23/35). Both needed.
*   **Answer:** **c) Both together**.

### Question 9
**Question:** Revolutions in time T? St1: T=20 min. St2: circumference speed = 3 m/min.
*   **Mental Trick:** Circumference = 2π×2 = 4π. Revolutions = speed×time/circumference. Need both speed and time. Together: 3×20/4π.
*   **Answer:** **c) Both together**.

### Question 10
**Question:** Are x,y,z consecutive? St1: Average = y. St2: y-x = z-y.
*   **Mental Trick:** St1: Mean = y → x+z = 2y → y is average. True for any AP, not just consecutive. St2: y-x = z-y → same as AP (equal spacing). Neither confirms spacing = 1. E.g., 2,4,6 satisfies both but not consecutive.
*   **Answer:** **e) Neither sufficient**.

### Question 11
**Question:** Who finishes last? St1: A beats B by 100, C by 60, D by 40. St2: B beats C by 20, D by 10.
*   **Mental Trick:** St1: A beats everyone → A is first. D beaten by least (40m) → D is 2nd. C beaten by 60 → C is 3rd. B beaten by 100 → B is last. Sufficient.
*   **Answer:** **a) Statement 1 alone**.

### Question 12
**Question:** Distance B to C? St1: B to D = 10m. St2: A to C = 12m.
*   **Mental Trick:** A-B-C-D in order. B to D = BC + CD = 10. A to C = AB + BC = 12. Two equations, three unknowns. Can't solve.
*   **Answer:** **e) Neither sufficient**.

### Question 13
**Question:** Articles on current affairs by staff with >5 yrs? Total articles unknown.
*   **Mental Trick:** 50% by staff, 60% on current affairs, 75% of current affairs by staff with >5 yrs. Need total articles.
*   St1: 20 staff articles → total = 40. Current affairs = 24. Staff >5yrs on CA = 0.75×24 = 18. Sufficient.
*   **Answer:** **a) Statement 1 alone**.

### Question 14
**Question:** When did Sonali leave? St1: Call at 9:15 AM at home. St2: Car reached office 10:15 AM, 45 min after leaving.
*   **Mental Trick:** St2: reached 10:15, took 45 min → left at 9:30. Sufficient alone.
*   **Answer:** **b) Statement 2 alone**.

### Question 15
**Question:** Is x = -11? St1: x² = 144 → x = ±12. Neither = -11. So answer is No. St2: x is natural → x > 0. So x ≠ -11. Yes.
*   **Mental Trick:** Actually x² = 144 → x = ±12. Since -11 ≠ 12 and -11 ≠ -12, x ≠ -11. Sufficient. St2: natural number → positive → x ≠ -11. Sufficient.
*   **Answer:** **d) Either statement alone**.
