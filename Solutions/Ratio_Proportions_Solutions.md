### Question 1
**Question:** a:b = 7:9, b:c = 3:5, c:d = 3:7. d is 25% more than e. Find a:e.
*   **Options:** `[A) 3/4  B) 1/4  C) 4/3  D) 4/5]`
*   **Mental Trick:** Chain ratios. a:b = 7:9. b:c = 3:5 → multiply to make b=9: b:c = 9:15. c:d = 3:7 → make c=15: c:d = 15:35. So a:b:c:d = 7:9:15:35. d = 1.25e → e = d/1.25 = 35/1.25 = 28. a:e = 7:28 = 1:4 = 1/4.
*   **Answer:** **B) 1/4**.

### Question 2
**Question:** Subtract what number from 47, 19, 56, 22 so remainders are proportional?
*   **Options:** `[A) 9  B) 5  C) 7  D) 3]`
*   **Mental Trick:** (47-x)/(19-x) = (56-x)/(22-x). Cross multiply: (47-x)(22-x) = (56-x)(19-x).
*   Try x = 3: 44 × 19 = 836. 53 × 16 = 848. ✗. Try x = 5: 42 × 14 = 588. 51 × 17 = 867. ✗.
*   Try x = 7: 40 × 12 = 480. 49 × 15 = 735. ✗. Try back-solve: actually expand.
*   1034 - 69x + x² = 1064 - 75x + x². 6x = 30. x = 5. Verify: 42/14 = 3. 51/17 = 3 ✅.
*   **Answer:** **B) 5**.

### Question 3
**Question:** Apples:Oranges = 3:14. Eat 5 apples → 1:8. Number of oranges?
*   **Options:** `[A) 56  B) 48  C) 52  D) 46]`
*   **Mental Trick:** Apples = 3x, Oranges = 14x. (3x - 5)/14x = 1/8. 24x - 40 = 14x. 10x = 40. x = 4.
*   Oranges = 14 × 4 = 56.
*   **Answer:** **A) 56**.

### Question 4
**Question:** Rs. 3456 among 2 men, 1 woman, 5 boys. Ratio = 8:5:3. Boy's share?
*   **Options:** `[A) 288  B) 480  C) 576  D) 460.8]`
*   **Mental Trick:** Total parts = 2(8) + 1(5) + 5(3) = 16 + 5 + 15 = 36. 1 part = 3456/36 = 96. Boy = 3 × 96 = 288.

### Question 6
**Question:** Box: 25p, 50p, Re.1 coins in 4:9:7. Diff between Rs from 25p and Re.1 coins = Rs.24. Number of 50p coins?
*   **Options:** `[A) 36  B) 16  C) 24  D) 70]`

### Question 7
**Question:** Workers in 3 shifts: 2:3:4. Add 64 each → 4:5:6. Total workers in all shifts?
*   **Options:** `[A) 480  B) 288  C) 352  D) 576]`
*   **Mental Trick:** 2x+64 : 3x+64 : 4x+64 = 4:5:6. (2x+64)/4 = (3x+64)/5. 10x + 320 = 12x + 256. 2x = 64. x = 32.
*   Total = (2+3+4) × 32 = 288.
*   **Answer:** **B) 288**.

### Question 8
**Question:** Coin value ∝ radius². R = 2cm → Rs.5. R for Rs.10?
*   **Options:** `[A) 2.83  B) 5  C) 3.23  D) 2.5]`
*   **Mental Trick:** V ∝ r². 5/10 = 4/r². r² = 8. r = √8 = 2√2 ≈ 2.83.
*   **Answer:** **A) 2.83 cm**.

### Question 10
**Question:** X:Y ratio. Add 3 to numerator, 1 to denominator → 2:1. Sum of X and Y?
*   **Options:** `[A) 4  B) 5  C) 6  D) 7]`
*   **Mental Trick:** (X+3)/(Y+1) = 2. X + 3 = 2Y + 2. X = 2Y - 1. X + Y = 3Y - 1. Try: Y=2, X=3 → sum=5. Check: 6/3 = 2 ✅. But X:Y = 3:2 are distinct ✅.
*   **Answer:** **B) 5**.

### Question 11
**Question:** Dog A takes 6 steps when B takes 7 and C takes 8. But 7A steps = 8B steps = 9C steps. Speed ratio?
*   **Options:** `[A) 432:441:448  B) 448:441:432  C) 196:192:189  D) same]`
*   **Mental Trick:** Let 7A = 8B = 9C = L. Step length: A = L/7, B = L/8, C = L/9.
*   Steps per unit time: A=6, B=7, C=8. Speed = steps × step length.
*   A: 6L/7. B: 7L/8. C: 8L/9. Multiply by 504/L (LCM of 7,8,9): 432 : 441 : 448.
*   **Answer:** **A) 432:441:448**.

### Question 12
**Question:** 4 numbers in proportion. Sum of squares = 50. Sum of means = 5. First two ratio = 1:3. Average?
*   **Options:** `[A) 12  B) 3  C) 6  D) 4]`
*   **Mental Trick:** Let numbers be a, b, c, d in proportion: a/b = c/d and ad = bc. Ratio a:b = 1:3 → a = x, b = 3x.
*   Sum of means = b + c = 5 → c = 5 - 3x. In proportion: ad = bc → xd = 3x(5-3x) → d = 3(5-3x) = 15-9x.
*   Sum of squares: x² + 9x² + (5-3x)² + (15-9x)² = 50.
*   10x² + 25 - 30x + 9x² + 225 - 270x + 81x² = 50. 100x² - 300x + 250 = 50. 100x² - 300x + 200 = 0. x² - 3x + 2 = 0. (x-1)(x-2) = 0.
*   x = 1: numbers = 1, 3, 2, 6. Avg = 12/4 = 3. x = 2: numbers = 2, 6, -1, -3 (negative, reject).
*   **Answer:** **B) 3**.

### Question 13
**Question:** Arsenal A. 40 recruits/month take 2 guns each for 5 months. Then 30 recruits/month. Guns last 45 months. A:B = 7:10. Guns in B?
*   **Options:** `[A) 4000  B) 3600  C) 4200  D) 3200]`

*   Total guns in A = 2800. A:B = 7:10. B = 2800 × 10/7 = 4000.
*   **Answer:** **A) 4000**.

### Question 14
**Question:** Three containers: alcohol:juice = 5:11, 3:2, 7:17. Mixed 4:5:6. Alcohol:juice ratio?
*   **Options:** `[A) 1/3  B) 2/3  C) 3/4  D) 4/5]`
*   **Mental Trick:** Alcohol fractions: 5/16, 3/5, 7/24. Weighted: (4×5/16 + 5×3/5 + 6×7/24)/15.
*   = (20/16 + 15/5 + 42/24)/15 = (1.25 + 3 + 1.75)/15 = 6/15 = 2/5. Ratio alcohol:juice = 2:3. As fraction 2/5. Hmm, the question asks for ratio. 2/5 is none of the options exactly. Let me recompute.
*   = (5/16 × 4 + 3/5 × 5 + 7/24 × 6) / (4+5+6) = (1.25 + 3 + 1.75)/15 = 6/15 = 0.4. So alcohol fraction = 2/5. Ratio A:J = 2:3. Option A) 1/3 means A:total. Hmm maybe they want A:(A+J) or just A/J. A/J = 2/3.
*   **Answer:** **B) 2/3**.

### Question 15
**Question:** Same setup. Add pure alcohol to 1L mixture to make 60% alcohol. How much?
*   **Options:** `[A) 450  B) 500  C) 550  D) 600]`
*   **Mental Trick:** Current alcohol in 1L = 400ml. Need (400 + x)/(1000 + x) = 0.6.
*   400 + x = 600 + 0.6x → 0.4x = 200 → x = 500 ml.
*   **Answer:** **B) 500**.

### Question 16
**Question:** A ∝ BC/D. A varies by 14/9, C by 8/3, D by 6/7. Find change in B.
*   **Options:** `[A) 2/3  B) 1/2  C) 1/3  D) 3/2]`
*   **Mental Trick:** A = kBC/D. New: (14/9)A = k × bB × (8/3)C / ((6/7)D).
*   14/9 = b × (8/3) × (7/6) = b × 56/18 = b × 28/9. So b = 14/9 × 9/28 = 1/2.
*   **Answer:** **B) 1/2**.

### Question 17
**Question:** Rs.500,000 invested. 20% CI for 3 years. A gets 91,000, B gets 113,750. Amount A invested?
*   **Options:** `[A) 128,950  B) 120,000  C) 125,000  D) 150,000]`
*   **Mental Trick:** Total amount after 3 years = 500,000 × (1.2)³ = 500,000 × 1.728 = 864,000. Total profit = 364,000.
*   C's profit = 364,000 - 91,000 - 113,750 = 159,250. Profit ratio = 91:113.75:159.25 = 364:455:637.
*   Simplify: ÷91 = 4:5:7. Total = 16. A's investment = 4/16 × 500,000 = 125,000.
*   **Answer:** **C) 125,000**.

### Question 18
**Question:** Milk:Water = 7:4. Sells 55L. Adds 20L water. New ratio 7:6. New quantity?
*   **Options:** `[A) 165  B) 15  C) 130  D) 185]`
*   **Mental Trick:** Let original = 11x. Milk = 7x, Water = 4x. After selling 55L: total = 11x - 55.
*   Milk left = 7x - 55×7/11 = 7x - 35. Water left = 4x - 55×4/11 = 4x - 20. Add 20L water: 4x.
*   Ratio: (7x - 35)/(4x) = 7/6. 42x - 210 = 28x. 14x = 210. x = 15.
*   New quantity = 11(15) - 55 + 20 = 165 - 55 + 20 = 130.
*   **Answer:** **C) 130**.

### Question 19
**Question:** Diamond value ∝ weight². Breaks into 5:6:7. Loss = Rs.21.4 lakhs. Original value?
*   **Options:** `[A) 42.8  B) 31.9  C) 32.4  D) 39.4]`
*   **Mental Trick:** Total weight = 18 parts. Original value ∝ 18² = 324. Pieces: 5²+6²+7² = 25+36+49 = 110.
*   Loss fraction = (324 - 110)/324 = 214/324. Let original = V. (214/324)V = 21.4.
*   V = 21.4 × 324/214 = 21.4 × 1.514 ≈ 32.4.
*   **Answer:** **C) 32.4 lakhs**.

### Question 20
**Question:** Tin 1: Water:Alcohol = 7:3. Tin 2: 5:4. Mix to get 2:1. Proportion?
*   **Options:** `[A) 9:4  B) 3:10  C) 4:9  D) 10:3]`
*   **Mental Trick (Alligation on alcohol fraction):** Tin 1 alcohol = 3/10, Tin 2 = 4/9. Target = 1/3.
*   |4/9 - 1/3| : |3/10 - 1/3| = |1/9| : |1/30| = 30:9 = 10:3. Tin1:Tin2 = 10:3.
*   **Answer:** **D) 10:3**.
