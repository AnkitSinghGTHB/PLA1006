### Question 1
**Question:** 56 litres, acid:base = 5:2. How much base to make 5:3?
*   **Options:** `[A) 10  B) 4  C) 8  D) 15]`
*   **Mental Trick:** Acid = 5/7 × 56 = 40L. Base = 16L. Need acid:base = 5:3. Acid stays 40L.
*   40/5 = 8 = one part. Base needed = 3 × 8 = 24. Add 24 - 16 = 8L.
*   **Answer:** **C) 8 lts**.

### Question 2
**Question:** 100 kg mixture. NaCl:Ammonium = 7:27. Add NaCl to make 10:27. How much NaCl?
*   **Options:** `[A) 6.7  B) 8.8  C) 9  D) 11.1]`
*   **Mental Trick:** Ammonium = 27/34 × 100 ≈ 79.41 kg (stays constant). Need NaCl/Ammonium = 10/27.
*   NaCl needed = 10/27 × 79.41 = 29.41 kg. Current NaCl = 7/34 × 100 = 20.59 kg. Add = 29.41 - 20.59 ≈ 8.82.
*   **Answer:** **B) 8.8 kg**.

### Question 3
**Question:** 15 kg A rice + 20 kg B rice. Sold at 40% more than A's price. No profit. Ratio CP(A):CP(B)?
*   **Options:** `[A) 10:17  B) 12:13  C) 17:10  D) 13:25]`
*   **Mental Trick:** Let A cost = a/kg, B = b/kg. Total CP = 15a + 20b. SP = 35 × 1.4a = 49a.
*   No profit: 49a = 15a + 20b → 34a = 20b → a/b = 20/34 = 10/17.
*   **Answer:** **A) 10:17**.

### Question 6
**Question:** 21g alloy. Zinc:Copper = 2:5. Add 30g zinc, remove copper so final ratio = 6:1. Copper removed?
*   **Options:** `[A) 5  B) 9  C) 15  D) 18]`
*   **Mental Trick:** Zinc = 6g, Copper = 15g. After adding 30g zinc: Zinc = 36g. Need Zinc:Copper = 6:1.
*   Copper needed = 36/6 = 6g. Remove 15 - 6 = 9g.
*   **Answer:** **B) 9 gm**.

### Question 7
**Question:** Three bottles: spirit:water = 4:1, 3:2, 2:1. Equal volumes mixed. Final ratio?
*   **Options:** `[A) 15:17  B) 23:27  C) 31:14  D) 12:15]`
*   **Mental Trick:** Let each = 30 ml (LCM for clean fractions).
*   Bottle 1: spirit = 24, water = 6. Bottle 2: spirit = 18, water = 12. Bottle 3: spirit = 20, water = 10.
*   Total spirit = 62, water = 28. Ratio = 62:28 = 31:14.
*   **Answer:** **C) 31:14**.

### Question 8
**Question:** 250 ml solution with 30% sugar. Add sugar to make 50%. How much?
*   **Options:** `[A) 50  B) 75  C) 90  D) 100]`
*   **Mental Trick:** Sugar now = 75g. Water = 175g. Need 50% → sugar = water. Sugar = 175g.
*   Add 175 - 75 = 100g. But wait: we're adding sugar as ml. Assuming density 1: add 100 ml.
*   **Answer:** **D) 100 ml**.

### Question 9 (labelled as Q8 in PDF)
**Question:** 120 ml milk+water. 2/5 milk, rest water. Add 168 ml milk. New ratio milk:water?
*   **Options:** `[A) 1:4  B) 1:3  C) 3:1  D) 4:1]`
*   **Mental Trick:** Milk = 2/5 × 120 = 48. Water = 72. After adding 168 ml milk: Milk = 216, Water = 72.
*   Ratio = 216:72 = 3:1.
*   **Answer:** **C) 3:1**.

### Question 10 (labelled as Q9 in PDF)
**Question:** Jar 1: milk:water = 7:4. Jar 2: 3:1. Fill 30L jar 3 with 1:1 ratio. Volume from jar 1?
*   **Options:** `[A) 7.5  B) 9.25  C) 12  D) Impossible]`
*   **Mental Trick:** Milk fraction: Jar 1 = 7/11, Jar 2 = 3/4. Target = 1/2.
*   Alligation: |7/11 - 1/2| : |3/4 - 1/2| = |3/22| : |1/4| = 3/22 : 1/4 = 12:22 = 6:11.
*   Jar 1 volume = 6/17 × 30 ≈ 10.59L. Hmm doesn't match options exactly—but let me recheck...
*   Actually the problem might have a twist. Let me try x from jar 1, (30-x) from jar 2.
*   Milk: 7x/11 + 3(30-x)/4 = 15. → 28x/44 + 33(30-x)/44 = 15. → 28x + 990 - 33x = 660.
*   -5x = -330 → x = 66. But jar only has some amount! x > 30 is impossible.
*   **Answer:** **D) It is impossible**.

### Question 11 (labelled as Q2 in PDF)
**Question:** Spirit costs Rs. 14.4/L. Adds water, sells at Rs. 12/L, makes 22.5% profit. Water:Spirit ratio?
*   **Options:** `[A) 27:35  B) 47:100  C) 100:47  D) 12:27]`
*   **Mental Trick:** CP of mixture per litre = SP/1.225 = 12/1.225 = Rs. 9.796/L.
*   Using alligation: Spirit at 14.4, Water at 0, mixture at 9.796.
*   Water : Spirit = (14.4 - 9.796) : (9.796 - 0) = 4.604 : 9.796.
*   Simplify: multiply by 1000: 4604 : 9796. Divide by 4: 1151 : 2449. Approx ratio ≈ 47:100.
*   **Answer:** **B) 47:100**.

### Question 12 (labelled as Q10 in PDF)
**Question:** Liquid 1: 24% benzene. Liquid 2: 36% benzene. Mix 5:7. Benzene %?
*   **Options:** `[A) 30%  B) 31%  C) 34%  D) 35%]`
*   **Mental Trick:** Weighted avg = (5×24 + 7×36)/12 = (120 + 252)/12 = 372/12 = 31%.
*   **Answer:** **B) 31%**.

### Question 13 (labelled as Q11 in PDF)
**Question:** Nitrous oxide: Rs. 136 and Rs. 145 mixed with third variety in 1:1:3. Mixture = Rs. 163/kg. Third variety price?
*   **Options:** `[A) 178  B) 178.5  C) 180.5  D) 185]`
*   **Mental Trick:** (1×136 + 1×145 + 3×x)/5 = 163. 281 + 3x = 815. 3x = 534. x = 178.
*   **Answer:** **A) Rs. 178**.

### Question 14 (labelled as Q12 in PDF)
**Question:** Two equal containers. One has 3× as much petrol as the other. Mixed: water:petrol = 3:2. Original ratios?
*   **Options:** `[A) 2:1, 3:4  B) 1:3, 1:2  C) 2:3, 4:1  D) None]`
*   **Mental Trick:** Let container size = 5 units each (total=10). Total petrol = 2/5 × 10 = 4. Let petrol in container 1 = p, container 2 = 3p. p + 3p = 4 → p = 1.
*   Container 1: petrol=1, water=4 → ratio 4:1 (water:petrol). Container 2: petrol=3, water=2 → ratio 2:3.
*   As water:petrol → C1 = 4:1, C2 = 2:3. Or expressed as ratios given in options: C) 2:3, 4:1 ✓ (water to petrol swapped ordering).
*   **Answer:** **C) 2:3, 4:1**.

### Question 15 (labelled as Q13 in PDF)
**Question:** 20L pure milk. Removed some, added equal water. Repeated. Now 64% pure. Amount removed initially?
*   **Options:** `[A) 4  B) 6  C) 6.6  D) 5]`
*   **Mental Trick:** After 2 removals of x litres: purity = ((20-x)/20)² = 0.64. (20-x)/20 = 0.8. x = 4.
*   **Answer:** **A) 4 litres**.

### Question 16 (labelled as Q14 in PDF)
**Question:** Three beakers A, B, C each 100ml. Spirit:water = A(1:3), B(1:4), C(2:3). Transfer 40ml A→C, then 28ml C→B. Final spirit ratio A:B:C?
*   **Options:** `[A) 3:6:8  B) 6:15:20  C) 15:28:42  D) None]`
*   **Mental Trick:** Initially: A has 25ml spirit in 100ml. B has 20ml in 100. C has 40ml in 100.
*   Transfer 40ml from A (spirit = 10ml, water = 30ml): A left = 60ml (15 spirit). C now = 140ml (50 spirit).
*   Spirit concentration in C = 50/140 = 5/14. Transfer 28ml C→B: spirit transferred = 28 × 5/14 = 10. Water = 18.
*   C left = 112ml (40 spirit). B now = 128ml (30 spirit). A = 60ml (15 spirit).
*   Ratio = 15:30:40 = 3:6:8.
*   **Answer:** **A) 3:6:8**.

### Question 17 (labelled as Q15 in PDF)
**Question:** Two nitrogen mixtures mixed 5:3. Mix 1: N:H:O = 4:5:1. Mix 2: 5:7:3. Dilute with O₂ to make 30% N. Ratio original:oxygen added?
*   **Options:** `[A) 4:2  B) 4:4  C) 4:1  D) 4:7]`
*   **Mental Trick:** N in mix 1 = 40%. N in mix 2 = 33.33%. Combined (5:3): N = (5×40 + 3×33.33)/8 = 37.5%.
*   8 parts have N = 3 parts. Need 3/Total = 30% → Total = 10. Add 2 parts O₂. Ratio = 8:2 = 4:1.
*   **Answer:** **C) 4:1**.
