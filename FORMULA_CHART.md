# 📊 The Ultimate Formula & Method Index

This is a pure reference chart containing every named trick, rule, and formula used across the Lateral Thinking syllabus. Use this for quick-reference memorization and last-minute cramming.

| Topic | Method / Trick Name | Exact Formula / Logic |
| :--- | :--- | :--- |
| **Mental Math** | SAW Method (Split & Distribute) | Split base: $69 \times 7 = (70-1) \times 7 = 490 - 7 = 483$ |
| **Mental Math** | Oz Method (Multiples of 5) | $\times 5 \rightarrow \frac{10}{2}$ \| $\times 25 \rightarrow \frac{100}{4}$ \| $\times 125 \rightarrow \frac{1000}{8}$ |
| **Mental Math** | Minions Method (Squares) | $(a+b)^2 \rightarrow a^2 \| b^2 + (2ab \times 10)$ |
| **Mental Math** | Mirror Squares | $12^2 = 144 \leftrightarrow 21^2 = 441$ \| $13^2 = 169 \leftrightarrow 31^2 = 961$ |
| **Mental Math** | Squares Ending in 5 | $N5^2 = [N \times (N+1)] \| 25$ |
| **Number System**| Divisibility by 3 & 9 | Sum of all digits must be divisible by 3 or 9. |
| **Number System**| Divisibility by 11 | Difference between alternating digit sums is 0 or multiple of 11. |
| **Number System**| Cyclicity Rule (Unit Digit) | Divide exponent by 4, use remainder as new exponent for the base unit digit. |
| **Number System**| Trailing Zeros in Factorial | Continuously divide by 5 and sum the quotients. |
| **Number System**| HCF & LCM | $LCM \times HCF = \text{Product of the two numbers}$ |
| **Percentages**  | Successive / Net Change | $A + B + \frac{A \times B}{100}$ |
| **Profit & Loss**| False Weight Formula | $Profit\% = \frac{\text{Error}}{\text{True Value} - \text{Error}} \times 100$ |
| **Profit & Loss**| Marked Price Ratio | $\frac{MP}{CP} = \frac{100 + Profit\%}{100 - Discount\%}$ |
| **Mixtures**     | Mixture Replacement Formula | $Final = Initial \times (1 - \frac{\text{Replacement Vol}}{\text{Total Vol}})^n$ |
| **Interest**     | Effective 2-Year CI Rate | $Effective\% = 2R + \frac{R^2}{100}$ |
| **Interest**     | 2-Year CI vs SI Difference | $Diff = P \times (\frac{R}{100})^2$ |
| **Interest**     | 3-Year CI vs SI Difference | $Diff = P \times (\frac{R}{100})^2 \times (3 + \frac{R}{100})$ |
| **Averages**     | The Deviation Method | Base + (Sum of Deviations / Total Number) |
| **Averages**     | Inclusion (Person Joining) | $New Person = Old Avg + (\text{Total New People} \times \text{Change in Avg})$ |
| **Averages**     | Weighted Averages | $A_w = \frac{n_1 \cdot A_1 + n_2 \cdot A_2}{n_1 + n_2}$ |
| **Ages**         | Constant Difference Rule | The numerical difference between two people's ages is always constant. |
| **Partnerships** | Golden Partnership Ratio | $Profit Ratio = (Investment_1 \times Time_1) : (Investment_2 \times Time_2)$ |
| **Time & Work**  | The LCM Method | Total Work = LCM of days. Add/Subtract efficiencies. No fractions! |
| **Time & Work**  | MDH Equivalence | $\frac{M_1 \times D_1 \times H_1}{W_1} = \frac{M_2 \times D_2 \times H_2}{W_2}$ |
| **Time & Work**  | Division of Wages | Wages are divided in ratio of **Work Done (Efficiency)**, not days. |
| **Time/Speed**   | Proportionality Rule | If Distance is constant: Speed Ratio $A:B$ $\rightarrow$ Time Ratio $B:A$ |
| **Time/Speed**   | Average Speed Formula | $\text{Avg Speed} = \frac{2 \times S_1 \times S_2}{S_1 + S_2}$ (For equal halves of distance). |
| **Time/Speed**   | Late / Early Formula | $Distance = \frac{S_1 \times S_2}{|S_1 - S_2|} \times \text{Time Difference (in hours)}$ |
| **Time/Speed**   | Train Crossing Logic | $Total Distance = Length_{Train} + Length_{Object}$. Convert kmph to m/s ($ \times \frac{5}{18}$) |
| **Time/Speed**   | Boats & Streams (Up/Down) | $Boat = \frac{Down + Up}{2}$ \| $Stream = \frac{Down - Up}{2}$ |
| **Time/Speed**   | Circular Tracks Meeting | Time to meet at start point = $LCM(Time\_Lap_A, Time\_Lap_B)$ |
| **Clocks**       | Golden Clock Formula | $Angle = \|30H - 5.5M\|$ |
| **Clocks**       | Repetition Stats (per 24hr)| Overlap ($0^\circ$) = 22x \| Opposite ($180^\circ$) = 22x \| Right Angle ($90^\circ$) = 44x |
| **Calendars**    | Odd Days Concept | Divide total days by 7, remainder = "Odd Days" to shift forward. |
| **Calendars**    | Year Repetition Rule | Leap Year = +28 yrs \| Leap+1 = +6 yrs \| Leap+2 or +3 = +11 yrs |
| **Reasoning**    | Photograph Family Tree | Start at the word **"MY"** and resolve backwards. |
| **Reasoning**    | Pythagorean Triples | $3-4-5$ \| $5-12-13$ \| $8-15-17$ (Use for shortest distance). |
| **Mensuration**  | Target Pi (11) Trick | Area/Volume involving $\pi$ is almost always a multiple of 11. |
| **Mensuration**  | Volume Constancy | Melted & recast objects: $Volume_{big} = N \times Volume_{small}$ |
| **Cubes**        | Painted Faces ($n \times n \times n$)| 3-face: 8 \| 2-face: $12(n-2)$ \| 1-face: $6(n-2)^2$ \| 0-face: $(n-2)^3$ |
| **Data Interp**  | Pie Chart Conversion | $1\% = 3.6^\circ$. To find %, divide degrees by $3.6$. |

| **Data Suff.**   | The Yes/No Trap | A definitive "NO" answer means the statement IS sufficient. |
