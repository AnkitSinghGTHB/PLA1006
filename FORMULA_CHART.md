## 📐 1. Mensuration (2D & 3D Geometry)

| Topic | Shape / Concept | Exact Formula / Logic |
| :--- | :--- | :--- |
| **2D Geometry** | Rectangle | Area = $L \times B$, Perimeter = $2(L+B)$, Diagonal = $\sqrt{L^2 + B^2}$ |
| **2D Geometry** | Square | Area = $a^2$, Perimeter = $4a$, Diagonal = $a\sqrt{2}$ |
| **2D Geometry** | Circle | Area = $\pi r^2$, Circumference = $2\pi r$ |
| **2D Geometry** | Semicircle | Area = $\frac{\pi r^2}{2}$, Perimeter = $\pi r + 2r$ |
| **2D Geometry** | Triangle (General) | Area = $\frac{1}{2} \times base \times height$ \| Heron's: $\sqrt{s(s-a)(s-b)(s-c)}$ |
| **2D Geometry** | Equilateral Triangle| Area = $\frac{\sqrt{3}}{4}a^2$, Height = $\frac{\sqrt{3}}{2}a$ |
| **2D Geometry** | Parallelogram | Area = $base \times height$, Perimeter = $2(a+b)$ |
| **2D Geometry** | Rhombus | Area = $\frac{1}{2} \times d_1 \times d_2$, Perimeter = $4a$ |
| **2D Geometry** | Trapezium | Area = $\frac{1}{2} \times (a+b) \times height$ |
| **2D Geometry** | Paths (Rectangle) | Outside = $2w(L+B+2w)$ \| Inside = $2w(L+B-2w)$ |
| **3D Geometry** | Cylinder | Vol = $\pi r^2 h$, CSA = $2\pi rh$, TSA = $2\pi r(r+h)$ |
| **3D Geometry** | Cone | Vol = $\frac{1}{3}\pi r^2 h$, CSA = $\pi rl$ (where $l = \sqrt{r^2+h^2}$), TSA = $\pi r(r+l)$ |
| **3D Geometry** | Sphere | Vol = $\frac{4}{3}\pi r^3$, Surface Area = $4\pi r^2$ |
| **3D Geometry** | Hemisphere | Vol = $\frac{2}{3}\pi r^3$, CSA = $2\pi r^2$, TSA = $3\pi r^2$ |
| **3D Geometry** | Cube | Vol = $a^3$, Surface Area = $6a^2$, Diagonal = $a\sqrt{3}$ |
| **3D Geometry** | Cuboid | Vol = $L \times B \times H$, TSA = $2(LB + BH + HL)$, Diag = $\sqrt{L^2+B^2+H^2}$ |
| **Mensuration** | Target Pi (11) Trick| Area/Volume involving $\pi$ is almost always a multiple of 11. |
| **Mensuration** | Volume Constancy | Melted & recast objects: $Volume_{big} = N \times Volume_{small}$ |
