This document contains step-by-step mental math strategies for the `Ratio, proportions & variations.pdf` practice set.

> [!TIP]
> **The Constant Identifier Trick:** In ratio problems where something is added or removed, ALWAYS identify which component *didn't change*, and multiply the ratios until that component's parts match perfectly.

### Question 1
**Question:** If a:b = 7:9, b:c = 3:5, c:d = 3:7 and d is 25% more than e, find the ratio between a and e.
*   **Options:** `[A) 3/4  B) 1/4  C) 4/3  D) 4/5]`
*   **Mental Trick (Chain Multiplication):**
    *   To find the ratio of the first term to the last term, simply multiply all the intermediate fractions.
    *   `a/e = (a/b) * (b/c) * (c/d) * (d/e)`
    *   `d is 25% more than e` means `d = 1.25e`, so `d/e = 125/100 = 5/4`.
    *   Multiply: `(7/9) * (3/5) * (3/7) * (5/4)`.
    *   Cancel out the identical top/bottom numbers instantly:
        *   7 cancels 7.
        *   5 cancels 5.
        *   `(3 * 3)` is 9, which cancels the 9.
    *   You are left with exactly `1/4`.
*   **Answer:** **B) 1/4**.

### Question 3
**Question:** Apples to Oranges ratio is 3:14. If five apples are eaten, ratio becomes 1:8. Find number of oranges.
*   **Options:** `[A) 56  B) 48  C) 52  D) 46]`
*   **Mental Trick (Lock the Oranges!):**
    *   Apples were eaten, so Oranges MUST remain constant.
    *   Old Ratio = `3 : 14`
    *   New Ratio = `1 : 8`
    *   Balance the Oranges (LCM of 14 and 8 is 56):
    *   Old Ratio (x4) = **12 : 56**
    *   New Ratio (x7) = **7 : 56**
    *   The Oranges are now matched at 56 parts. 
    *   Look at the apples: dropped from 12 parts to 7 parts. Drop = **5 parts**.
    *   This drop was caused by eating **5 apples**.
    *   `5 parts = 5 apples`  →  `1 part = 1 apple`.
    *   Since Oranges are 56 parts, there are 56 oranges.
*   **Answer:** **A) 56**.

### Question 4
**Question:** Rs. 3456 is divided among 2 men, 1 woman, 5 boys. The ratio of the SHARE of an individual man, woman, and boy is 8:5:3. Boy's share?
*   **Options:** `[A) Rs. 288  B) Rs. 480  C) Rs. 576  D) Rs. 460.8]`
*   **Mental Trick (Total Value Base):**
    *   Multiply the number of people by their individual share ratio to get the total split volume.
    *   2 Men = `2 * 8 = 16 parts`.
    *   1 Woman = `1 * 5 = 5 parts`.
    *   5 Boys = `5 * 3 = 15 parts`.
    *   Total Parts = `16 + 5 + 15 = 36 parts`.
    *   `36 parts = 3456`.
    *   Mental division: 3600 is 100 parts. 3456 is exactly 144 less than 3600. 144 is `4 * 36`. So it's `100 - 4 = 96 parts`.
    *   `1 part = 96`.
    *   Individual boy's share = 3 parts = `3 * 96 = 288`.
*   **Answer:** **A) Rs. 288**.

### Question 6
**Question:** Box contains 25p, 50p, 1Re coins in ratio 4:9:7. Number of 50p coins if difference in amount yielded by 25p and 1Re is Rs. 24?
*   **Options:** `[A) 36  B) 16  C) 24  D) 70]`
*   **Mental Trick (Value Mapping):**
    *   Convert Coin ratios into Value ratios by multiplying by their Rupee denomination.
    *   25p Value = `4 coins * 0.25 = 1 Value Part`.
    *   50p Value = `9 coins * 0.50 = 4.5 Value Parts`.
    *   1Re Value = `7 coins * 1.00 = 7 Value Parts`.
    *   Difference between 1Re and 25p Value = `7 - 1 = 6 Value Parts`.
    *   `6 Value Parts = Rs. 24`  →  `1 Value Part = Rs. 4`.
    *   Total value of 50p coins = `4.5 * 4 = Rs. 18`.
    *   If you have Rs. 18 made entirely of 50p coins, you must have `18 * 2 = 36 coins`.
*   **Answer:** **A) 36**.

### Question 7
**Question:** Workers in 3 shifts are 2:3:4. If 64 workers are added in each shift, ratio becomes 4:5:6. Total initial workers?
*   **Options:** `[A) 480  B) 288  C) 352  D) 576]`
*   **Mental Trick (Universal Shift):**
    *   Initial = `2 : 3 : 4`
    *   New = `4 : 5 : 6`
    *   Notice that EVERY single shift increased by exactly **2 parts**.
    *   Since every shift added 64 workers, that means `2 parts = 64 workers`.
    *   `1 part = 32 workers`.
    *   Total initial workers = `2 + 3 + 4 = 9 parts`.
    *   Total = `9 * 32 = 288`.
*   **Answer:** **B) 288**.

### Question 19
**Question:** Value of a diamond is proportional to square of its weight. Broken into pieces measuring 5:6:7, causing a loss of Rs. 21.4 lakhs. Actual value?
*   **Options:** `[A) 42.8 lakhs  B) 31.9 lakhs  C) 32.4 lakhs  D) 39.4 lakhs]`
*   **Mental Trick (Square Part Drop):**
    *   Original total weight = sum of pieces = `5 + 6 + 7 = 18 parts`.
    *   Original Value = `(18)^2 = 324 value parts`.
    *   New Value = Sum of squared pieces = `(5^2) + (6^2) + (7^2)` = `25 + 36 + 49 = 110 value parts`.
    *   Loss incurred = `324 - 110 = 214 value parts`.
    *   We are told the loss is **21.4 lakhs**.
    *   So, `214 parts = 21.4 lakhs`  →  `1 part = 0.1 lakhs`.
    *   Actual original value = `324 parts = 324 * 0.1 = 32.4 lakhs`.
*   **Answer:** **C) 32.4 lakhs**.
